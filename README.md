# AI Design Weekly

Skill que genera un newsletter semanal, en formato email, con las novedades de IA de los últimos 7 días aplicadas a diseño de producto, UX/UI y diseño visual.

Weekly email-style digest of AI news for product, UX/UI and visual designers (in Spanish).

## Instalación

```
npx skills add natiazuniga-hue/Skill_ai-design-weekly
```

## Cómo usarla

Pedile a tu agente algo como:

- "¿Qué pasó esta semana en IA y diseño?"
- "Pasame las novedades de IA para UX/UI"
- "Armame el newsletter de IA y diseño"
